 Role Overview
 Junior Data Analyst – Job Description
 A Junior Data Analyst is responsible for collecting, processing, and analyzing data to support business decision-making. This role involves transforming raw data into meaningful insights using analytical tools, dashboards, and reports.
 Key Responsibilities
 Collect, clean, and validate data from multiple sources
 Analyze datasets to identify trends, patterns, and insights
 Create dashboards and reports for business stakeholders
 Write SQL queries to extract and manipulate data
 Perform data visualization using tools like Power BI or Tableau
 Assist in data modeling and reporting processes
 Collaborate with cross-functional teams to understand data requirements
 Ensure data accuracy, consistency, and integrity
 Automate repetitive data tasks and reporting processes
 Document data processes and analysis findings
 Required Skills
 Strong knowledge of SQL for data querying
 Proficiency in Excel (Pivot Tables, VLOOKUP, formulas)
 Basic knowledge of Python or R for data analysis
 Understanding of data cleaning and preprocessing techniques
 Familiarity with data visualization tools (Power BI, Tableau)
 Basic knowledge of statistics and data analysis concepts
 Problem-solving and analytical thinking skills
 Preferred Skills
 Experience with data visualization tools (Power BI, Tableau)
 Familiarity with ETL processes
 Basic understanding of databases (MySQL, PostgreSQL)
 Knowledge of business intelligence concepts
 Exposure to cloud platforms (AWS, Azure, Google Cloud Platform)
 Experience with pandas, NumPy, or similar libraries
 Tools & Technologies
 Languages: SQL, Python/R
 Tools: Excel, Power BI, Tableau
 Databases: MySQL, PostgreSQL
 Libraries: pandas, NumPy
 Platforms: Windows/Linux
