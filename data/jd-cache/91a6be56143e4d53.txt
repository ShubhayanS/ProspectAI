 💼 Job Title: Agentic AI Engineer (Python)
 📍 Location: Central New Jersey
 🏢 Company: BeaconFire Inc.
 🕒 Job Type: Full-Time
 🌍 Visa Sponsorship : Available (E-Verified Employer)
 🔹 About Us
 BeaconFire Inc. is a New Jersey–based technology consulting firm specializing in software development, web development , and business intelligence solutions. We are seeking a skilled Agentic AI Engineer to design and productionize advanced AI systems using modern RAG and agent-based architectures.
 🔹 Role Overview
 As an Agentic AI Engineer , you will own the end-to-end development of RAG-based AI systems on Google Cloud Vertex AI. This includes ingestion pipelines, retrieval systems, agent orchestration, evaluation, and deployment. You will work with modern AI frameworks and databases to build scalable, production-ready intelligent systems.
 🔧 Key Responsibilities
 Design and develop high-quality web applications using Python, Flask, and Django
 Build and optimize RAG pipelines (chunking, embeddings, indexing, retrieval, reranking, grounding)
 Develop agentic workflows (tool usage, planning, guardrails, structured outputs)
 Conduct code reviews and ensure maintainable, reusable code
 Perform testing to ensure system reliability and performance
 Create and maintain technical documentation
 Collaborate on project planning, estimation, and prioritization
 Define and run evaluation frameworks (retrieval metrics, hallucination checks, answer quality)
 Deploy production systems (APIs, CI/CD, monitoring, cost optimization, security best practices)
 ✅ Basic Qualifications
 Strong experience in Python (Python 3) development
 Understanding of software development lifecycle and testing practices
 Knowledge of relational databases (e.g., MySQL, PostgreSQL)
 Experience with version control tools like Git
 Hands-on experience building RAG systems (hybrid search, reranking, embeddings, prompt design)
 Familiarity with at least one agentic framework such as:
 LangChain / LangGraph
 LlamaIndex
 Semantic Kernel
 AutoGen
 Solid understanding of vector search and experience with at least one vector database
 Strong engineering practices (testing, telemetry, secure design, reliability mindset)
 🎯 Preferred Qualifications
 Master’s degree in Computer Science or related field
 Experience with Flask or Django web frameworks
 Experience building RESTful APIs
 Familiarity with cloud platforms such as AWS or GCP
 Experience with Google Cloud Vertex AI and GCP services (IAM, Cloud Run, GKE, logging/monitoring)
 Knowledge of graph-based RAG (entity linking, traversal, retrieval fusion)
 Experience with streaming tools (Pub/Sub, Kafka) and document pipelines
 Familiarity with evaluation tools (RAGAS, TruLens) and prompt/version management
 Exposure to frontend frameworks (React, Next.js) or internal tooling
 🎯 Why Join Us?
 💼 Competitive compensation and growth opportunities
 🌍 Visa sponsorship available
 🤝 Collaborative and innovative team environment
 📈 Work on cutting-edge AI and LLM systems
 🚀 Opportunity to build production-grade agentic AI solutions.
